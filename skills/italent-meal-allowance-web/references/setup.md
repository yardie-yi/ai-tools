# 首次配置与依赖安装

## 1. 先收集用户配置

配置路径：有 `XDG_CONFIG_HOME` 时使用其下的 `italent-meal-allowance-web/profile.json`；否则使用 `~/.config/italent-meal-allowance-web/profile.json`。`~` 表示当前用户主目录，不使用创建本技能者的绝对路径。

文件不存在、JSON 损坏、字段为空或缺少任意必填项，都视为配置尚未完成。首次询问示例：

> 首次使用需要你提供：①餐补工作簿链接，②iTalent 考勤入口链接，③预期员工姓名。请一次发给我。

本次请求已提供部分字段时，只询问其余字段。三项未齐全前停止，不打开考勤页、不读取餐补表，也不写入业务数据。完整姓名或链接不要从旧聊天和本技能的历史案例中补猜。

收到三项后，去除首尾空白；两个链接必须是完整的 HTTPS 地址，有主机名且不含 URL 用户名或密码。餐补链接应为飞书 `/sheets/` 或 `/wiki/` 资源；考勤入口应为用户提供的 iTalent 页面。无法识别或员工姓名为空时，说明具体问题并请求更正。URL 格式有效不代表当前账户拥有访问权限，后续仍需核对。

按以下字段保存用户实际输入：

| 字段 | 含义 |
| --- | --- |
| `workbook_url` | 餐补工作簿链接，保留用户明确指定的工作表参数 |
| `attendance_url` | iTalent 考勤入口链接 |
| `expected_employee` | 预期员工姓名 |

本机文件只保存这三项，不保存密码、Cookie、访问令牌或临时跳转会话参数。目录权限使用 `0700`，文件权限使用 `0600`；只在三项有效后写入完整 JSON。配置不放入技能目录，因此同步或更新技能不会带走个人配置。没有持久文件访问能力时明确说明限制，当次使用用户输入，不假装已经保存。

已有完整配置时直接复用；新任务覆盖值以本次要求为准。只有用户明确要求修改默认配置时，才持久更新已有配置。

## 2. 检查实际安装状态

配置完成后、读取业务数据前，检查当前可用技能清单和实际 `SKILL.md` 文件。Codex 常用安装位置为 `${CODEX_HOME:-$HOME/.codex}/skills`，也要识别 `~/.agents/skills` 或当前平台已列出的技能根目录。可读取的现有技能直接复用；不能仅因本轮清单未刷新就反复安装。只安装缺失项，不覆盖用户定制版本，不修改插件缓存或其他无关技能。

| 依赖 | 何时需要 |
| --- | --- |
| `lark-shared` | 所有飞书操作 |
| `lark-sheets` | 读写餐补电子表格 |
| `lark-wiki` | 餐补链接路径包含 `/wiki/` |

发现缺失的飞书 CLI 或配套技能后，由 agent 按下节指定的官方指南执行安装并验证；其他依赖按各自说明处理。不要把可以自行完成的安装交给用户手工执行，不编造安装来源。

## 3. 按官方指南安装飞书 CLI 和配套技能

飞书安装任务统一使用以下入口：

> 帮我安装飞书 CLI：https://open.feishu.cn/document/no_class/mcp-archive/feishu-cli-installation-guide.md

由 agent 实际打开并读取上述官方指南，按照其当前内容完成缺失的 CLI、运行时和配套技能安装，不把这句话转交用户执行。安装命令、技能来源及流程以指南为准；指南无法读取时报告实际错误，不能声称安装完成。

- 先检查已有安装、应用配置和登录状态，只补齐缺失项，复用可用配置，不为本次任务无条件升级或新建应用，也不覆盖用户定制技能。
- 安装 CLI 和安装配套技能分别验收：确认 `lark-cli --version` 可执行，所需飞书技能的实际 `SKILL.md` 及其引用文件可读取；Wiki 链接另需对应技能。读取安装后的技能说明再操作。
- 首次应用配置、登录和授权按官方指南及 `lark-shared` 执行。需要浏览器交互时由用户完成；已有有效配置和授权时跳过重复初始化。按实际任务申请权限，不自行扩大范围，不输出应用密钥或访问令牌。
- 安装完成后执行 `lark-cli auth status`，并按当前技能文档核对用户身份及目标资源权限；程序安装成功不代表已登录或有表格访问权限。
- 安装或认证失败时保留已执行命令和脱敏错误，查明原因后按指南处理；同一阻塞再次出现就停止。不要让用户手工寻找安装包或复制安装命令。

## 4. 发现宿主内置浏览器

先检查当前实际暴露的工具及其说明。若宿主提供浏览器技能，读取该技能和相关文档后使用对应工具。直接使用宿主提供的浏览器能力，按其实际工具文档操作。

确认工具能打开目标页面、返回可读取的当前状态，并支持点击、输入、翻页和滚动。权限、认证和 iframe 能力按当前工具文档处理。宿主仅有搜索或链接打开功能时，报告缺失的交互或读取能力，停止业务读取和写表；不要假装普通技能安装能够提供宿主未暴露的权限。

## 5. 安装后的验收与失败处理

1. 逐个确认所需飞书技能存在可读取的 `SKILL.md` 及引用文件，加载后执行操作；技能清单尚未刷新时按实际路径读取，避免重复安装。
2. 检查 `lark-cli --version` 和当前命令帮助，再按 `lark-shared` 检查用户身份、认证及所需资源权限。版本成功不等于已授权，也不代表考勤读取成功。
3. 用宿主浏览器实际打开或选择配置的 iTalent 页面，核对登录员工与目标月份。保留工具返回证据，不以配置文件或链接代替页面身份检查。
4. 安装失败时先查明原因，按对应官方指南或依赖说明处理；相同阻塞仍存在就停止，返回缺失项、已尝试命令和实际错误。需要用户完成登录、MFA 或授予必要权限时再请其处理；继续使用已确认可用的宿主浏览器，授权范围仅限本任务所需。
