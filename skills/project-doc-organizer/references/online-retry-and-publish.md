# 在线读取、重试与发布

在线来源需要浏览器、出现失败/不完整读取、用户要求重试，或向云端输出时读取。采用当前平台工具和技能的实际接口，不把某次任务的ID、域名、错误码或恢复脚本硬编码进通用流程。

## 读取失败的处置

| 实际结果 | 下一步与记录 |
| --- | --- |
| 连接器/API成功但只有页面壳、摘要或缺正文 | 通过原平台另一种读取方式或已登录浏览器打开同一来源，核对实际正文 |
| 用户已授权browser-harness或其他浏览器方式 | 读取已安装的对应技能，沿用授权立即重试失败集合；不再次询问是否允许浏览器 |
| 登录墙、认证失效 | 保留具体站点和错误，使用现有登录会话；确需用户登录时只提出该阻塞，继续其他站点。不要从原文取口令自动输入 |
| 连接关闭、TLS/证书错误、超时 | 区分网络与账号权限；合理重试或切换已有可用读取方式，不反复请求同一失败端点，不绕过证书/访问控制 |
| 无权限/已删除的合并提示 | 原样记录歧义，不替平台断言是哪一种 |
| 附件可预览、原文件不可得 | 读取可用预览，记录转换形式及未覆盖的原文件结构；不要冒称完整原文件读取 |
| 权限设置查询失败、正文可读 | 正文读取继续；单列共享范围依据，不把设置查询错误写成正文错误 |

重试围绕已有失败队列进行。共享认证问题可以标记同站分支受阻，但仅实际请求过的URL计为“已重试”。再次失败仍按实际错误保留缺口；恢复访问后从原来源ID续作，并继续展开新发现引用，不重复分析已确认未变的来源。

浏览器使用正文所在容器而非助手面板或整页壳。SPA导航后核对URL、标题与正文已稳定；附件预览前核对卡片标题/附件ID，切换前关闭旧预览，确认新预览确已对应目标。截图/下载后校验页数、名称或文件特征；旧弹窗内容不能被保存成新附件。

原始抓取、网络事件和签名下载地址可能含凭据，留在受限临时目录；交付只记录脱敏URL、状态和必要证据。浏览器操作权与已打开的任务标签由一个操作者协调，沿用当前技能的标签与导航规则。

## 把权限判断与产物模式分开

共享范围按 `SKILL.md` 的规则判断，不由读取错误码自动决定。用户已指定云端输出且授权覆盖该内容和目标时直接写入。读取权限、共享设置查询权限、允许复制范围是不同事实；记录判断所依据的范围信息及尚未核实处。

根据本次实际决定记录产物模式：

| 模式 | 正文 |
| --- | --- |
| 摘要 | 已读内容的短摘要，带适用范围和原文依据 |
| 仅入口 | 原文链接、实际读取状态及采取此模式的具体原因；不混入技术摘要 |
| 未完成说明 | 未取得正文时的来源、失败原因、缺口；不冒充内容总结 |

临时仅入口须向用户说明与所要求正文输出的差距；不能把仅入口页数量计为完成的正文摘要。保留已有可用摘要和发布身份，避免一次权限或网络波动清空历史内容。

## 可恢复的云端写回

采用平台已有发布功能；只有批量或重复任务确需自动化时才补脚本，不为少量页面搭建框架。发布负责人串行维护登记和写操作，其他读取/核验可并行。

1. **本地准备**：登记`source_id → summary_path → target_document_id/url`。保存选定发布项的模式、目标目录、草稿哈希、共享依据及预期目标版本。使用平台支持的草稿校验；先拿代表性页面验证格式转换，再扩大批次。同一未变草稿无需因无关项失败反复全量校验。
2. **保护现有内容**：已登记来源复用目标ID。更新前读取当前版本与内容，确认仍是预期的本任务产物，使用revision/条件更新能力；遇到人工修改先保留差异，不覆盖。目标位置不明确时先定位，不以同名为依据重复创建。
3. **先留凭据再验证**：写操作前记入日志；新建返回ID后立即保存ID/URL和响应，再做回读。逐次证据使用追加编号或独立运行目录，重跑不能覆盖旧证据。文件保存用临时文件替换，避免半写登记。
4. **回读确认**：比较正文文本、顺序、结构、关键链接和目标目录，不能只比字符数。区分已读来源、已生成摘要、云端写入和完整回读各自数量。服务只返回部分成功或warnings时核实具体影响。
5. **断点恢复**：响应成功但回读失败时，先按保存ID只读核对实际结果，符合预期后补登记并跳过该项；禁止再次创建。响应丢失且无ID时先通过目标目录、请求回执等定位结果；未排除已有创建前停止该项写入。确认未发生写入后才重试。
6. **发布后导航**：生成真实发布链接的路由/可视页，再校验目标目录全部分页及索引链接。已验证项保持不变，只重试未完成项；来源、草稿或范围证据变化时重新准备受影响项。

服务可能改写默认样式、空白、Unicode或URL编码。先对比真实请求与回读，只有已证明不改变语义的差异才做有边界的规范化，并验证“正文缺失、顺序变化、不同链接仍失败”。不要对所有URL使用`unquote_plus`或一律解码保留字符；`+`、编码斜线、附件ID、版本/查询参数可能改变目标。未知差异暂停该项，不通过弱化比较掩盖错误。

## HTML 文件交付

生成 HTML 且需要云端输出时，在正文发布、真实导航链接补齐后执行。沿用上面的版本保护、先登记再验证和失败恢复流程；HTML 是生成产物，单独登记，不计入来源数。

1. **准备可移植文件**：检查 `href`、`src` 和样式资源引用。文档入口使用已发布的云端 URL；所需样式、脚本、图片内嵌或随产物交付，确保脱离本地目录仍能使用。本地知识库、审计记录尚无云端目标时改为准确的文字说明或标注仅本地可用，不伪造云端链接。仍需保留的本地版与云端版分别登记哈希。
2. **上传原文件**：按目标平台技能上传最终 `.html`，保留源文件与样式；转换为在线文档、截图或预览不能替代 HTML 文件交付。先解析目标容器类型，上传到用户指定目录。无需为文件交付另建网站或扩大分享权限。
3. **复用文件身份**：保存产物路径、目标文件 ID/URL、父目录或 Wiki 节点、可得的版本、字节数、SHA-256 和写入/验证状态。后续导航变化同步更新登记文件，平台支持时原位替换；不支持时保留旧版，登记新旧关系并修复入口，说明限制。不要按标题反复创建同名文件。
4. **回验与交付**：核对真实父目录及完整分页，按已保存 ID 下载原文件，与上传版本比较字节数和 SHA-256（或逐字节比对）。只能取得转换预览时，标记原文件一致性未核验。保存命令、结果及差异，给出实际文件链接。分别说明已上传、可下载、平台可在线预览和已实际显示的状态；本地桌面/窄屏检查不能证明平台在线预览，也不能替代下载回验。

## 状态与交付

读写日志保存实际工具/命令、当前结果、版本、来源范围和未核实事项。日期使用本次会话提供的日期；缓存和历史验证保留原日期，不把旧结果刷新成“今天已核验”。

重试前快照用于对比，当前台账用于生成导航，临时草稿用于恢复；三者分别标识。统计旧失败恢复数与递归新增数，最终只声称证据支持的部分完成程度。共享范围或登录仍缺信息时列具体补齐条件，不泛称“需要管理员权限”。
