# 项目文档整理与知识库

读全来源，交付便于开发时查阅的短摘要和路由。默认中文 Markdown，保留原文代码标识、命令和路径。用户要求优化本 skill 时，只维护技能，不重新执行资料整理。

## 任务约定

从对话提取并持久记录：初始来源、输出位置、项目根目录、递归边界、篇幅偏好、代码核验范围及已有访问授权。后续“再简短些”“重试失败项”等要求更新同一任务；已明确的范围和授权不重复询问。缺少必需的来源或输出位置且上下文无法确定时才补问。

项目根目录默认取调用时工作目录。先读适用的 `AGENTS.md` 和已有知识库；启动必读资料按项目规则读取，但只有进入本次来源链才计入总结。来源与输出目录分别记录，生成物不作为新来源。

- **默认递归范围**：用户给出的来源及其正文、表格、卡片、内嵌文档和附件中的文档引用，持续到没有新引用；按稳定身份去重，无静默深度上限。
- **“只处理我给的文档，但递归”**：采用上述引用闭包，不从空间侧栏、全站搜索、相邻目录或代码搜索增加独立入口。外站文档若由正文明确引用，仍按内容判断；不能仅因域名或非本项目标签排除。
- **代码核验**：用户要求结合代码，或当前任务在授权范围内确需代码证据时开展。代码暂不可用只影响对应结论，不阻塞文档整理。严格引用范围下，代码核验不自动扩大总结集合。
- **云端输出**：用户指定目标目录即授权在该处创建或更新本任务产物；先准备可核验内容，再按文末的共享范围规则执行。保留原文、人工内容及无关文件。

## 1. 建账、读取、递归

读取 [引用发现与代码核验](references/discovery-and-code.md)。以一份来源台账驱动队列、摘要、索引和统计；小任务可用 Markdown，大批量或断点续作使用结构化台账，并由它生成展示页。

每个独立来源保留稳定 ID、原名、URL/路径及别名、版本或哈希、所有父来源与具体位置、读取证据、缺口、唯一摘要路径。分别记录**正文读取、引用展开、共享范围、发布结果**；正文已读、文件已生成或云端仅有入口，都不等于完整交付。

优先使用对应平台工具或技能取得全文，检查分页、末尾、隐藏工作表及内嵌内容。图片、流程图、扫描件等需要视觉核验；转换预览不能证明原文件隐藏内容已读。摘要要求简短不降低来源读取要求。具体格式与身份处理见引用参考。

遇到登录、连接、权限、解析失败，或用户要求重试、使用已授权浏览器时，读取 [在线读取、重试与发布](references/online-retry-and-publish.md)。继续可读分支；没有旧总结的失败来源生成明确的“未完成总结”说明。有旧总结时保留已核实正文和版本，另加本次无法核验提示。

并行读取可按独立来源分组；协调者维护唯一来源队列、别名与发布登记。共享浏览器由单一操作者使用。工作者回传来源、父位置、版本、已读范围和新增引用，合并去重后再发布。

完成读取阶段的标准：所有已发现引用都有明确处置；每份已读正文有证据，部分可读有缺失范围，未读分支的下级引用注明尚无法穷尽。只有全部范围枚举及正文读取完成，才称“全部文档已整理”。

## 2. 写短摘要与开发路由

写文件前读 [交付结构与字段](references/deliverables.md)。为每个独立来源生成 `原名＋总结.md`，沿用登记路径；同名来源用稳定 ID 子目录区分。只去掉已识别的末尾文件扩展名，保留标题中的点号、版本号和重复扩展名的其余部分。

默认一段用途加 3–5 条开发常用信息，复杂文档按实际需要增加。优先保留：适用版本/硬件、常用命令与执行目录、配置对应关系、接口约束、日志入口和关键注意事项。用户要求更短时直接压缩，不再次确认；完整提取记录、长下载列表和审计细节放台账或证据文件，用一条链接进入。

摘要开头包含原文入口、版本、读取日期和完整性；关键事实紧邻章节/页码/单元格依据。命令保留参数、引号、顺序、执行环境和必要前提；原文缺失的必要字段标明未说明，不为每篇填满空模板。冲突保留双方版本，不默认新版替代旧版。真实口令、密钥、令牌用占位符替换，原始缓存限制访问，批量输出先脱敏。

`项目开发指导.md` 以常用任务为入口，固定保留 **文档路由表** 和 **缺失的必要内容（文档或其他）**。按需链接主题子索引，所有未排除来源可达；主指南不重复粘贴逐篇内容。代码流程/通信 ID 派生资料仅在有证据且范围允许时生成，单独标明非原始设计文档。

整理技术操作只读取和核对，不执行构建、部署、刷机、重启、清日志或附件脚本；将“已核对原文”和“实际运行结果”分开。

## 3. 知识库、云端与可视导航

复用项目知识库；没有时建立 `.project-knowledge/` 的 `INDEX.md`、`sources.md`、`facts.md`、`access.md`，按交付参考接入指南和来源。重要约束、硬件配置、接口契约附证据与日期。仅维护 `AGENTS.md` 中一个稳定标记入口，保留原有规则、原文必读和权威工作树要求。

有云端输出时，按 [在线读取、重试与发布](references/online-retry-and-publish.md) 保存来源→目标文档 ID 的登记、版本保护和回读证据。复用已有页面，不按标题重新创建；发布失败先核实已有结果，再继续。

用户同时指定 show-me 等可视技能时，找到并读取该技能，与整理工作共享同一台账和真实链接。图示只承载任务导航、覆盖状态和缺口，不再生成一份长总结；依赖尚未发布的页面时先完成发布，再补导航。网页产物检查桌面和窄屏实际效果，区分“请求打开”和“已经显示”。该可视分支只在被要求或确有需要时执行。

本次生成了 HTML 且指定云端输出位置时，HTML 源文件也同步到同一目录；用户另定位置或仅需本地时遵从其要求。需要云端交付的 HTML 每次更新后，按 [HTML 文件交付](references/online-retry-and-publish.md#html-文件交付) 核对可移植链接、发布身份与下载回验，不能停在本地生成或截图预览。

## 4. 增量与交付核验

重跑按稳定身份和版本/内容差异更新受影响项；保留人工补充及历史已核验内容。路径迁移同步修复入口。仅把能证明由本任务生成、未被当前台账/发布登记/导航引用的废弃中间稿移入可恢复归档，记录路径和哈希。

交付前保存实际命令、结果和局限，核对：

- 初始来源和所有已发现引用都有状态；身份、别名、摘要路径去重，全部正文结论有来源。资源清单与独立文档数分别统计。
- 常用命令、硬件参数、接口契约及版本冲突与原文一致；摘要和日志无凭据，未运行操作没有被写成成功。
- 本地链接存在，所有来源从路由可达，AGENTS入口唯一且原有约束保留。
- 云端正文、链接、目录归属和分页回读通过；仅入口页、未完成说明与正文摘要分别计数，缺口不能被写入成功掩盖。
- 统计由最终台账及发布回读生成；保留重试前后分母，旧失败恢复数与新发现数分开报告。

最终简短给出可用结果链接、前后变化、验证命令与实际结果、未完成项及补齐条件；详细证据放验证记录。只优化 skill 的请求交付技能改动及验证，不继续操作原任务云端。

## 共享范围与权限

读取结果、原文操作要求和允许输出的范围分别判断。权限查询失败不等于正文无权限或禁止复制，也不因一次失败把所有来源改为仅入口。结合实际来源/目标范围和用户已有授权判断，授权充分时直接执行。

确有受限内容扩大可见范围，或完成该判断实际缺少必要信息时，指出具体缺失项；继续已获授权部分。仅入口可以作为明确说明的临时替代，不能冒充用户要求的正文总结。用户若授权变更ACL，按具体对象、主体、目标范围操作并回读；普通整理不改变ACL。
