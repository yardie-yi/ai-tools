# 初始化或迁移项目配置

只在用户要求初始化、迁移或补全本 Skill 的项目配置时使用。本页是执行入口；[USAGE.md](USAGE.md) 保留详细字段说明，遇到具体字段不明确时按标题查阅，不必预读全文。

1. 确认目标模块和现有 `.evospec/module.config.yaml`，先查看已有改动；已有配置应合并，不用模板覆盖。
2. 从与目标能力相关的 README、构建脚本、CI、源码和规则中提取配置。只查所需模块和文件；不做全库扫描。记录关键字段的证据来源。
3. 仓库证据明确且低风险的值可直接填写。多个候选或涉及远端、设备、正式部署/push 目标的值，先说明候选；真正阻塞时再请用户决定。秘密值不写入仓库。
4. 未确认的高影响能力保持禁用或留作未解析配置；不要用模板示例、其他项目或历史对话中的值补齐。
5. 验证 YAML、相关路径和启用配置的占位符。仅对本次配置涉及的能力做静态检查或安全 dry-run；真实构建、部署和 push 按用户目标及权限边界分别判断，不作为初始化的固定收尾步骤。

交付时说明已配置的能力及证据、仍未确认的字段、实际执行的检查和可用范围。不要因无关配置项未完成而阻塞已完成的部分。
