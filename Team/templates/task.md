# Team 任务单

复杂任务复制到目标项目合适的任务目录；已有任务单时合并所需字段，不另建平行记录。简单任务无需填写整张表。示例字段以本次实际内容替换。

## 范围与基线

- 目标、产物与不涉及的范围：
- 用户已授权操作、可写文件/远端字段：
- 项目规则与来源/版本/阅读状态：
- 当前源码快照（提交及未提交差异）、候选产物身份：
- 原文要求 / 代码事实 / 假设 / 设计建议：
- 阻断决定及可独立继续的部分：

## 验证与反馈

每条证据记录：执行时间、目录/设备、命令、退出码、源码/产物身份、实际结果、日志路径及未覆盖项。

| 阶段或切片 | 状态 | 证据 | 修复轮次与预算 | 下一动作 |

状态按验收项填写 PASS / FAIL / BLOCKED / NEEDS_DECISION；保留初始失败及每轮复测。原需求缺陷与新增需求分开记录。
