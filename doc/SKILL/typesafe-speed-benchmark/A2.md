1. **了解用途与前提**  
   Ponytail 是约束编码助手实现方式的技能／插件：先理解需求，再优先复用现有代码、标准库和平台能力；它不是业务程序调用的运行时 SDK。Windows 安装前需准备可用的 Codex CLI 和 Node.js，确保 hook 的 PATH 中能找到 node。可在终端用 `codex --version`、`node --version` 检查。

2. **在终端安装**  
   依次执行以下两条命令，不要把它们当成聊天中的 slash 指令。检查终端结果，确认安装是否成功。

   ```powershell
   codex plugin marketplace add DietrichGebert/ponytail
   codex plugin add ponytail@ponytail
   ```

3. **激活并新开任务**  
   安装后在终端运行 `codex`，进入交互界面，用 `/hooks` 查看实际脚本并按界面流程信任。随后重启 Codex 桌面版，在目标项目中新开任务。安装成功不代表所有 hook 已生效，需确认实际输出。

4. **第一次调用与验证**  
   在新任务中通过 `@` 查找并选择 Ponytail，初次可单独发送 `@ponytail lite`；插件缺省为 full。随后提出一个小任务：先读 AGENTS.md、相关代码和调用处，优先复用，不新增不必要依赖，并运行项目要求的验证。确认技能可找到、模式符合预期、助手读取实际代码且改动限于明确需求。务必在实际项目中验证，涉及硬件时保留必要校准与时序要求。
