1. **了解用途与前提**

   Ponytail 是约束编码助手实现方式的技能／插件：先理解需求，再优先复用现有代码、标准库和平台能力。它不是业务程序调用的运行时 SDK。安装前需有可用的 Codex CLI 和 Node.js，并确保 hook 的 PATH 能找到 node；可用 `codex --version`、`node --version` 检查。

2. **在终端安装**

   在 Windows 终端依次执行以下两条命令；它们不是聊天中的 slash 指令：

   ```powershell
   codex plugin marketplace add DietrichGebert/ponytail
   codex plugin add ponytail@ponytail
   ```

3. **激活并新开任务**

   安装后在终端运行 `codex`，进入交互界面，用 `/hooks` 查看实际脚本，按界面流程信任。随后重启 Codex 桌面版，在目标项目新开任务。当前 hook 配置包含 SessionStart、SubagentStart、UserPromptSubmit 三类事件。

4. **首次调用与验证**

   在新任务中通过 `@` 查找并选择 Ponytail，首次可单独发送 `@ponytail lite`。lite 是试用建议，插件缺省为 full。随后提出一个小任务：先读 AGENTS.md、相关代码及调用处，优先复用，避免不必要依赖，运行项目要求的验证。确认技能可找到、模式符合预期、助手读取实际代码且改动紧扣需求。安装成功不代表所有 hook 已生效，应检查实际输出，并在实际项目中验证。
