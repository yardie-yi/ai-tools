1. **了解用途与准备环境**

   Ponytail 是编码助手的技能／插件，让助手先理解需求，再优先复用现有代码、标准库和平台能力；它不是业务程序需要调用的运行时 SDK。安装前，确保 Windows 已有可用的 Codex CLI 和 Node.js，并确保 hook 的 PATH 能找到 node。

2. **在终端安装**

   打开终端，依次执行以下两条命令，不要把它们当作聊天中的 slash 指令：

   ```powershell
   codex plugin marketplace add DietrichGebert/ponytail
   codex plugin add ponytail@ponytail
   ```

3. **信任 hook 并激活新任务**

   安装后在终端运行 `codex`，进入交互界面，通过 `/hooks` 查看实际脚本，并按界面流程信任。随后重启 Codex 桌面版，在目标项目中新开任务，让新会话加载插件。

4. **第一次调用与验证**

   在 Codex 中输入 `@`，查找并选择 Ponytail 技能。初次建议单独发送 `@ponytail lite`；lite 适合试用，插件缺省为 full。随后提出一个小任务：先读 AGENTS.md、相关代码和调用处，优先复用，不新增不必要依赖，并运行项目要求的验证。

   确认技能可找到、模式符合预期、助手确实读取实际代码，且改动围绕明确需求。安装成功不等于所有 hook 已生效，应检查实际输出，并在实际项目中完成验证。
