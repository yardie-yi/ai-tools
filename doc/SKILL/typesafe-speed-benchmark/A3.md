1. **了解用途与准备环境**  
   Ponytail 是约束编码助手实现方式的技能／插件：先理解需求，再优先复用现有代码、标准库和平台能力，不是业务程序的运行时 SDK。安装前准备可用的 Codex CLI 和 Node.js，在终端用 `codex --version`、`node --version` 检查，并确保 hook 的 PATH 中能找到 `node`。

2. **在终端安装**  
   依次执行以下两条命令；它们是终端命令，不是聊天中的 slash 指令：
   ```powershell
   codex plugin marketplace add DietrichGebert/ponytail
   codex plugin add ponytail@ponytail
   ```

3. **激活并新开任务**  
   安装后在终端运行 `codex`，进入交互界面，通过 `/hooks` 查看实际脚本，按界面流程信任。随后重启 Codex 桌面版，在目标项目中新开任务，让新会话加载插件。

4. **首次调用并验证**  
   在任务中通过 `@` 查找并选择 Ponytail，初次建议单独发送 `@ponytail lite`；插件缺省模式为 full。再提出一个小任务：“先读 AGENTS.md、相关代码和调用处，优先复用，不新增不必要依赖，运行项目要求的验证。”确认技能可找到、模式符合预期、助手读取了实际代码且改动符合明确需求。安装成功不代表所有 hook 已生效，应检查实际输出，并在实际项目中完成验证。
