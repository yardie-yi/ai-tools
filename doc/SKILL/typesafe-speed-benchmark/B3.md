1. **了解用途与准备环境**

   Ponytail 是约束编码助手实现方式的技能／插件：先理解需求，再优先复用现有代码、标准库和平台能力。它不是业务程序运行时需要调用的 SDK。Windows 安装前，请确认 Codex CLI 和 Node.js 可用，可在终端检查 `codex --version` 与 `node --version`，并确保 hook 的 PATH 能找到 `node`。

2. **在终端安装**

   依次执行以下两条命令；它们是终端命令，不是聊天中的 slash 指令：

   ```powershell
   codex plugin marketplace add DietrichGebert/ponytail
   codex plugin add ponytail@ponytail
   ```

3. **信任 hook 并激活新任务**

   安装后在终端运行 `codex`，进入交互界面，用 `/hooks` 查看实际脚本并按界面流程信任。随后按 README 要求重启 Codex 桌面版，在目标项目新开任务。安装成功不代表所有 hook 已生效，需结合实际输出确认。

4. **第一次调用与验证**

   在新任务中通过 `@` 查找并选择 Ponytail，首次建议单独发送 `@ponytail lite`；`lite` 是试用建议，插件缺省为 `full`。再提出一个小任务：先读 AGENTS.md、相关代码和调用处，优先复用，避免不必要依赖，并运行项目要求的验证。确认技能可找到、模式符合预期、助手读取了实际代码且改动仅覆盖明确需求。务必在实际项目中验证效果。
